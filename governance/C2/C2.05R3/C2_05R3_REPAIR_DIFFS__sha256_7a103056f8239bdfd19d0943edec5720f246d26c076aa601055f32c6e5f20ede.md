## B03 — executed-request scope binding

### Before R3
R2 improved provenance by binding `CapabilityRequirement R` and the exact C2.02R2 attempted-response set. The remaining C2.05-native dimensions were only sealed in a pre-dispatch coverage provenance record. That record was not machine-required as an input to the actual request-construction/dispatch path.

R2 also stated that multiple provenance refs claiming one attempt were invalid, but it did not freeze the finite authority domain over which those claims were discovered.

### R3 delta
- add `EXECUTED_REQUEST_SEMANTIC_STATE`;
- require the same exact state ref to be consumed by request construction/dispatch and replay-retained for the attempt;
- bind native subject, identifier namespace, partition, constraint and temporal dimensions to that executed state;
- make any unrepresented coverage-relevant request semantic condition render the attempt coverage-ineligible;
- require the already-closed `REQUEST_SCOPE_CONFORMANCE` certification check for any coverage-capable certification profile;
- make `OperationCoverageProvenance` exactly project the executed state while preserving R2 exact R and attempted-response provenance;
- add `OPERATION_COVERAGE_AUTHORITY_BINDING` as the exact singular attempt-retained provenance authority slot;
- explicitly forbid mutable/global provenance claim scans;
- make later unreferenced claims non-authoritative for historical replay.

This directly targets residual failures `C2-481` and `C2-557` plus the independent-review adequacy defect affecting the old `C2-567..C2-571` tests.

## B04 — operation-bound composite root + explicit semantic decomposition

### Before R3
R2 made composite roots carry empty query/response semantic sets and treated the component-scope set as the root query/response universe. That removed informal equivalence but contradicted the inherited operation scope predicate because the exact C2.02R2 attempted-response set always contains the endpoint primary response semantic and therefore cannot equal an empty root response set.

### R3 delta
R3 selects the other repair form explicitly allowed by the R2 independent review:

```text
COMPOSITE_EXPLICIT_CLOSURE root:
  root.required_query_semantic_refs
    = exact consuming operation required-query set

  root.required_response_semantic_refs
    = exact consuming operation C2.02R2 attempted-response set A
```

The R2 empty-root rule is superseded.

R3 adds `COMPOSITE_SCOPE_DECOMPOSITION_RELATION`:
- exact root scope/snapshot/component/query/response sets;
- exact QUERY and RESPONSE decomposition axes;
- every root semantic key exactly once;
- every component semantic ref exactly once on the corresponding axis;
- exact component-scope membership;
- no missing/extra/duplicate/cross-axis mappings;
- no human/provider/schema-similarity inference.

R2 exact component-scope and partition closure remain mandatory. Semantic decomposition is an additional independent predicate and cannot be substituted by partition union.

This directly targets residual failures `C2-471`, `C2-540`, `C2-584`, and `C2-585`.
